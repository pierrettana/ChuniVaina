# Changelog

## 1.1.1

- Renamed the internal workflow UI module to avoid an unrelated PyInstaller package hook that prevented building the application.

## 1.1.0

Changes since the public 1.0.0 release:

- Added an unchecked-by-default `data.conf` export checkbox, conditional version fields, and an explanation of test-menu listing and possible version conflicts. Custom content can load with or without it.
- Added guidance against reusing official IDs or likely future official ranges, especially for songs; scanning cannot predict future allocations.
- Added a task-focused default tab, character category/ownership forms, relevant tools, next-step guidance, and visible project save status. Advanced fields and XML remain available.
- Added a guided character creator with category, ownership and linked artwork setup.
- Updated public credits and wording. The removal-only 1.0.1 build was not released.

Build the macOS and Windows applications on their respective platforms.
